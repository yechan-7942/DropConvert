# DropConvert v0.1.0-beta

파일 업로드 없이 Mac에서 문서와 이미지를 변환하는 메뉴 막대 앱의 첫 베타입니다.

## 다운로드와 설치

- `DropConvert-0.1.0-beta-arm64.dmg`: Apple Silicon용 테스트 빌드
- `SHA256SUMS.txt`: 다운로드 파일의 SHA256
- DMG 안의 앱을 Applications로 옮겨 실행하고 메뉴 막대 아이콘을 누릅니다.
- Word·HWP 변환은 **문서 변환 준비 → 필요한 기능 설치**를 한 번 실행합니다.
- 최초 문서 도구 설치에는 인터넷과 수백 MB의 여유 공간이 필요합니다.

## 포함한 기능

- 이미지 → PNG/JPG/PDF, PDF 첫 페이지 → PNG/JPG
- Word DOCX → PDF, HWP 5 → Word/PDF
- Word DOCX → HWP 5: 별도 파서로 원문 글자 보존 확인 후 저장
- 문서 도구의 앱 내 설치, 다운로드 검증, 중복 설치 방지와 재시도
- 원본 보존, 결과 파일명 중복 회피, 완료 후 Finder에서 열기
- 선택 기능인 YouTube 저장: yt-dlp·ffmpeg는 별도 설치 필요

## 알려진 제한사항

- **개발용 로컬 서명이며 Apple Developer ID 서명·공증 미적용입니다. macOS가 실행을 차단할 수 있습니다.**
- 다른 Mac과 Intel Mac의 설치·실행은 아직 검증하지 않았습니다.
- HWP는 베타 기능입니다. 글꼴·표·수식·도형·머리말·꼬리말·쪽 배치는 달라지거나 일부 개체가 누락될 수 있습니다.
- 원문 글자 보존 검사도 실제 글꼴 표시와 레이아웃을 보장하지 않습니다. 제출·인쇄 전 원본과 비교해 주세요.
- 한 번에 한 파일을 처리합니다. PDF → 이미지는 첫 페이지만 저장하며 OCR·PDF → Word·HWPX는 지원하지 않습니다.
- 자동 설치는 문서 도구 대상입니다. 문서·이미지는 업로드하지 않지만 도구 설치와 YouTube 저장에는 인터넷을 사용합니다.

## 검증

자동 검사 19개 통과, 외부 HWP 원본 지정이 필요한 검사 1개 생략.
별도 설치 폴더에서 설치·변환·재설치를 확인하고, 앱의 설치 버튼과 첫 PDF 변환도 직접 확인했습니다.
한글 렌더링 회귀 검사, 잘못된 다운로드·문서 거부, 원본 보존과 중복 파일명 검사도 포함합니다.
이 검사는 실제 새 Mac 테스트를 대체하지 않습니다.

오류는 [이슈 양식](https://github.com/yechan-7942/DropConvert/issues/new/choose)으로 알려 주세요.
개인정보가 있는 원본 문서는 공개 이슈에 올리지 마세요.
